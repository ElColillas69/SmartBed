I used generative AI to help build SmartBed. That covers the React dashboard, the revised database schema, the FastAPI rewrite of the backend, the MQTT link (including TLS), the Raspberry Pi script, the frontend sign-in, the deployment files, the README and the architecture diagram.

Tests will be continuously done regardless of initial reviews to confirm ongoing integration. The deployment and MQTT TLS were then tested on the real AWS server, including a reading published as the Pi over port 8883.
